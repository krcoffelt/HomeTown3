## Reference Entries

### REF-01: Stat Section (CANAAN)
- Pattern: high-impact stat strip on light background.
- Key cues:
  - Strong metric scale contrast (`2 Days`, `500+`, `20 Hours`).
  - Sparse, centered composition.
  - Uppercase micro-label for trust framing.
  - Serif accent only on selective phrase (`actually see`).

### REF-02: Dark Portfolio Intro (Portfolite)

## Implementation Translation (Non-negotiables)
1. Keep a **light editorial base** for most sections.
2. Use **dark sections intentionally** for hero/proof contrast moments.
3. Apply serif accent only to selective key phrases, never entire paragraphs.
4. Preserve large heading scale and generous whitespace.
5. Avoid generic icon-card grids and decorative gradients.
6. Make the Website Design offer visually dominant in service contexts.
